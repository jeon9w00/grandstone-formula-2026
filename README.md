# Grandstone Formula 2026

Original browser-based Formula-style racing game prototype.

## Run
Open `index.html` in a modern browser, or deploy this repository as a static site.

## Controls
- W / Up: throttle
- S / Down: brake
- A / D: steer
- Space: boost
- O: overtake mode
- C: camera
- M: strategy panel
- R: reset
- P / Esc: pause

## Notes
This repository is intentionally separate from `Grand-Prix.io`.
